本项目用于从豆包、千问等支持的 AI 对话及分享页面中提取图片和视频资源，提供以下使用方式：

1. Chrome / Edge 浏览器扩展
2. Firefox 浏览器扩展
3. Tampermonkey 油猴脚本
4. 本地 Web 页面与 Python API

群内主要用于使用问题交流、Bug 反馈、新页面适配需求、功能建议以及安装部署交流。

- 使用的浏览器及版本
