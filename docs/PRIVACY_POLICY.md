# AI Media Extractor 隐私政策

生效日期：2026-08-19

AI Media Extractor（以下简称“扩展”）只在用户打开并授权匹配的豆包、千问页面时工作。扩展读取页面中用于展示图片或视频的网络响应，以便在本地生成素材列表和下载链接。

扩展不会把聊天内容、媒体内容、Cookie、账号信息或网络响应上传到开发者服务器，也不会用于广告、分析或用户画像。扩展设置（目前为是否自动下载新素材）只使用浏览器提供的本地扩展存储保存，不会同步到云端；卸载扩展后由浏览器清除。

开启自动下载后，扩展会在检测到新的图片或视频地址时发起浏览器下载。该功能默认关闭，用户可以随时在扩展弹窗中关闭。下载文件的保存位置和浏览器的下载提示由浏览器管理。

扩展访问第三方站点时，仍受这些站点的服务条款和隐私政策约束。用户应只下载自己有权访问和保存的内容。

隐私问题可通过项目仓库的 Issues 联系维护者：<https://github.com/scj725/ai-media-extractor/issues>。
